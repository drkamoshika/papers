# ダッシュボードの基礎文献

ダッシュボードの「基礎文献」から、確認済みの文献を分野・出典・本文で検索し、目的・手法・結果・新規性・限界を画面内で読める。

7分野を件数付きのラベルとして常時表示する。新着論文を表示中でも、分野を選ぶと基礎文献へ切り替えて絞り込める。基礎文献と「両方」の表示では、分野・出典・検索を組み合わせられる。一覧と詳細にも所属分野のラベルを付け、詳細のラベルからも絞り込める。

分野名は総覧の7分類と一致させ、古典12件は「古典・共通基礎（別冊）」として別枠で表示する。複数分野の論文はそれぞれに含め、合計件数は論文IDで重複を除く。ラベルは既存の`fields`を用い、新着論文へ内容から推測した分類を付けない。選択した文献集と分野はURLに残り、再読み込みやリンク共有でも保たれる。

新着論文は従来の`papers.json`、基礎文献は`foundations.json`を読む。後者は`reports/foundations/`の照合済みMarkdownから作成した公開用データであり、`catalog.json`の未照合候補は掲載しない。分野横断の重複はIDでまとめる。

基礎文献の内容項目と`date`・`reportDate`の区別は新着レポートと共通。古典にはDOIや出版社識別子、出版社・NISTの出典を認め、存在しないarXiv IDへ変換しない。日付が日単位で確認できない場合は`date: null`を保持する。`fields`は文献集内の分野、`extraSource`・`sourceSections`は本文の確認箇所を表す。

`read_level: abstract`は要旨まで、`full_text`は記載した本文の関連箇所までの照合を表し、全頁の精読・再現実験の完了を意味しない。

基礎文献の更新は、内容を一次資料へ照合してMarkdownと公開用JSONを保存した時点で反映する。ブラウザは保存済みJSONを読み込むだけで、文献探索や要約生成は行わない。新着論文の定期実行・JSON再構築の仕組みは変更していない。
