# 研究領域マップ・動向レビュー

ダッシュボードの「研究マップ・動向レビュー」は、従来の「全体マップ」と「研究動向レビュー」を統合した単一のリビングレビュー。7分野について、基礎からの系譜、手法と研究間の関係、現在の到達点、直近の進展、根拠、重要文献、未解決課題を同じ画面で読む。

- 入口: https://drkamoshika.github.io/papers/?view=map
- 分野の例: https://drkamoshika.github.io/papers/?view=map&topic=events
- 文章版: [reports/overviews/README.md](../reports/overviews/README.md)
- 更新仕様: [LIVING_REVIEW.md](LIVING_REVIEW.md)

## データ構造

公開用の正本は `overview.json`。分野全体の長期的な構造に加え、`livingReview` に最新週・分野横断の論点・週次履歴、各分野の `currentUpdate` に現在地・理解の変化・新しい根拠・境界・次の課題・重要文献を持つ。

`reports/overviews/*.md` は同じ体系の文章版、`reports/weekly/*.md` は変更履歴である。週次レポートは独立した累積レビューではなく、どの根拠で正本をどう更新したかを残す監査記録として扱う。

## 根拠の範囲

2026-11-21版は基礎774件・日次301件、重複を除く1,073件を母集団とし、長期的な詳細レビューでは代表192件を引用する。11月17〜21日の週次追加38件は既存の7分野へ追加で位置づけた。全1,073報の全文を今回独立に再読したという意味ではなく、個別の確認範囲は論文データと週次記録に従う。

技術の系譜、論文間の位置づけ、研究機会は編者の統合的解釈であり、直接の引用関係や因果的な連鎖を主張しない。異なるデータ・分割・指標の結果は統一順位へ変換しない。

## 表示と検証

`overview.js` と `overview.css` が一覧・分野別の詳細・最新更新を表示する。旧 `trends.html` は既存URLを統合画面へ転送する。`python scripts/validate_living_review.py` は7分野の更新日、週次履歴、必須セクション、文献ID、HTTPSリンク、重複データの不在を検査する。
