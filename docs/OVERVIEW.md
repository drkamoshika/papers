# 全体マップ

ダッシュボードの「全体マップ」は、基礎文献と新着論文をつなぐ7分野の横断レビュー。比較表から分野別本文、引用論文の要約・一次資料へ移動できる。

- 入口: https://drkamoshika.github.io/papers/?view=map
- 分野の例: https://drkamoshika.github.io/papers/?view=map&topic=events
- 文章版: [reports/overviews/README.md](../reports/overviews/README.md)

各分野は、基礎からの積み上げ、現在の到達点と使える条件、直近研究、次の課題、分野間の接点、読む順番を持つ。技術の系譜や展望は編者の整理と明記し、実験での成功・実運用での有効性・因果的な説明を混同しない。

初版のレビュー日は2026-11-16。母集団は基礎774件・新着264件の計1,038件で、代表165件を引用し、30の技術領域を整理した。収録論文の公開日上限は2026-11-12、レポート日上限は2026-11-16。代表22件の一次資料を追加照合し、確認先と日付は公開用JSONと文章版の参考文献に記録した。個別要約全件の全文再精読を意味しない。

公開用の`overview.json`と`reports/overviews/*.md`は手動編集の同じレビューを表す。既存の`papers.json`・`foundations.json`や定期実行は変更していない。新規論文の追加だけではこのレビューは自動更新されず、版の日付と対象件数を明示して更新する。

マップは`overview.js`・`overview.css`で表示する。レビューの読み込み失敗は論文一覧から独立させ、既存のarXiv・PubMed等の出典ボタンは一覧で常時選択できる状態を保つ。基礎文献の分野パネルは基礎文献タブだけに表示する。

検証: 7分野の描画、165件のIDと既存文献の一致、30領域の内容、引用と要約の往復、URL再読み込み、目次移動、基礎文献一覧への遷移、既存の出典絞り込みを確認。PCと390px幅の表示で横スクロールと本文内の独立スクロールがないことも確認した。
