### Paper: Large language model applications for real-time clinical mental health assessment: Current potential and future directions

- Source: PubMed

- Publication date: 2026-08-03
- URL: https://pubmed.ncbi.nlm.nih.gov/42545345
- read_level: abstract
- Tags: medical LLM, mental health, clinical assessment, scoping review
- Summary: LLMが患者と直接対話してscreening/diagnosis/symptom monitoringを行う研究をpreregistered scoping reviewで整理。該当したのは10研究のみで、structured interview、domain adaptation、clinical reference standardを使う研究ほど良い傾向だった。
- Objective: LLMが患者と直接対話して行うメンタルヘルスのスクリーニング、診断・症状モニタリングに関する実証研究の現状、能力、研究不足を明らかにする。
- Methods: 事前登録したスコーピングレビューとして英語・中国語文献を検索し、単なる医療QAやカルテ要約ではなく、LLMが患者と直接対話して精神状態を評価する実証研究だけを抽出。診断面接・分類、症状の重症度推定、マルチモーダルなうつ評価へ分類し、構造化面接・臨床参照基準や領域調整の有無を比較した。

- Novelty: 医療情報の一般的な回答性能と、患者へ直接介入する評価の妥当性を分けて整理。実務上は検査面接の標準化、症状スケール、患者群での基準ラベルが揃わなければ、モデル間の性能を比較すること自体が難しい。
- Limitations: わずか10研究で初期・非学術誌の報告も含むため、実際の心理的安全性、症状変化の追跡、医療者に代わる評価の妥当性を示したものではない。

### Paper: Deep learning maps local brain aging in relation to cognition across human adulthood

- Source: PubMed
- Canonical ID: pmid:42546187
- Publication date: 2026-08-03
- URL: https://pubmed.ncbi.nlm.nih.gov/42546187
- read_level: abstract
- Tags: deep learning, neuroimaging, brain age, Alzheimer's disease
- Summary: global brain ageを単一値で出す代わりに、T1 MRIからvoxel-level local brain ageを推定。14,748人の認知正常者で学習し、MCI/ADではfrontotemporal領域のaccelerated agingが進行することを示した。
- Objective: 全脳を単一の年齢差に要約する方法では見落とす、領域別脳老化の違いと認知低下・アルツハイマー病との関係を測定する。
- Methods: 多施設の認知正常者14,748人のT1強調MRIを使い、全脳の平均的な脳年齢でなくボクセルごとの局所脳年齢（LBA）を深層学習で推定。得られた年齢偏差の空間分布を認知正常者、軽度認知障害（MCI）、アルツハイマー病（AD）で比較し、各領域の局所年齢と認知機能の関連性を調べた。
- Data and results: 通常加齢で前頭・側頭領域に相対的に高い局所年齢がみられ、MCIからADへの段階では前頭側頭領域の加速がさらに顕著となり、疾患早期の病理が関連する皮質・皮質下構造にも差が現れた。局所偏差と認知成績に関連がみられたが、公開要旨から一部の検定統計量や患者群の正確な分母を読み取れないため補わない。
- Novelty: 『この脳は実年齢より何歳上か』という単一値を脳領域ごとの地図に分解し、認知との対応を検討できるようにした。研究上の価値は分類スコアの改善だけでなく、どの部位に変化が分布するかという解剖学的な仮説を得られる点にある。
- Limitations: MRIの横断比較に基づく局所年齢は、個人の将来の認知低下速度を直接示すものではない。施設・撮像条件差、正常者を使う訓練分布、外部の将来予測における校正を検証する必要がある。

### Paper: Pandora's AI Model Routing Box: Efficient Allocation with Costly Value Estimation

- Source: arXiv
- Canonical ID: arxiv:2608.20316
- Publication date: 2026-08-20
- URL: https://arxiv.org/abs/2608.20316
- read_level: abstract
- Tags: model routing, inference efficiency, value of information, multi-model systems
- Summary: 複数のAIモデルや推論設定から、どれにqueryを割り当てるかというrouting問題を「価値推定そのものにもコストがかかる」Pandora's Box問題として定式化。高価な評価器を必要な場合だけ呼ぶrouting policyを導出する。
- Objective: 複数AI専門モデルへの問い合わせ振り分けで、性能予測を精密化する際の評価器コストも考慮し、品質と推論費用を最適化する。
- Methods: モデルごとの期待価値推定を高価な検査付き探索であるPandora's Boxとして定式化。ガウス信号モデルの下で価値情報量の閉形式を導出し、集中型Pandora's Routerと、各専門モデルが自己評価費用を負担する分散型Pandora's Bidderを設計。
- Data and results: 複数LLMの標準評価、検索拡張専門モデル、推論時の思考計算を変えるモデルの3領域で評価。集中型ルータは全候補に高価な評価を行う方式と同等のルーティング品質を保ちつつ高価な評価器の使用を大幅削減。分散型は他の推定が正確なら効率改善するが、ノイズが大きいと一部モデルの利得が他者を犠牲に増えると報告。
- Novelty: モデル推定誤差だけでなく推定そのものの費用を意思決定の対象とし、情報価値に基づいて高価な評価器を呼ぶか決める理論。
- Limitations: 閉形式はガウス信号の仮定に依存する。分散型の結果は競合モデルの推定ノイズに敏感であり、戦略的な行動による不公平が起こり得る。

### Paper: Phantom Gains: Auditing Self-Improvement Against a Measured Null

- Objective: LLM自己改善で報告される『個々の問題が新たに解けた／解けなくなった』という遷移を、推論時の測定ノイズと真の能力変化に分離する。

- Novelty: 能力獲得・喪失を推定する統計量それぞれに、同じ評価条件を通した凍結対照から測定上の帰無分布を直接構築する方法。
- Limitations: 元モデルが一度も正解しなかった問題群では証拠が不十分と著者らが明記。実験はQwen3-8B等に限定される。

- Limitations: ナラティブな知見整理であり、提案する多領域モデルの外部検証や術後痛の削減効果を実証していない。急性痛と慢性痛を同一のラベルで扱うべきでもない。

### Paper: A Machine Learning and Large Language Model Tool for Systematic Literature Reviews of Health Economic Evidence: A Validation Study

- Source: PubMed
- Canonical ID: pmid:42525208
- Publication date: 2026-07-29
- URL: https://pubmed.ncbi.nlm.nih.gov/42525208
- read_level: abstract
- Tags: LLM, machine learning, systematic review, health economics
- Summary: health economic systematic reviewをML screener + LLM criteria screenerで再現。title/abstract screeningは95%以上のaccuracyだったが、full-text screeningは80%未満に落ち、複雑なmodel structureのdata extractionも弱かった。
- Objective: 医療経済評価の系統的文献レビューで、機械学習・LLMによる検索、採否スクリーニング、情報抽出の精度と効率を人手作業と比較する。
- Methods: 慢性副鼻腔炎（鼻茸を伴う）の医療経済評価を対象とした既存の人手による系統的文献レビューを、Nested KnowledgeのML Robot ScreenerとLLM Smart Screenerで再実行。文献検索、タイトル・要旨による採否判定、全文判定、経済モデルの属性抽出を分けて、人間による元レビューの判定・データ抽出に対する一致と作業時間を測定した。
- Data and results: 自動検索は人手レビューのPubMed収録43報中22報（51%）しか回収できなかった。タイトル・要旨判定は95%超の正確率だが、全文採否は80%未満へ低下。複雑な健康状態・感度分析・シナリオ分析の区別にも誤りが残る。時間短縮見積は検索・一次スクリーニング約60%、抽出約20%。処理が速くても検索漏れによる系統的な選択バイアスが残る。
- Novelty: 医療経済の系統的レビューで『検索→選別→全文確認→複雑な数理モデル情報の抽出』を段階別に検証した点。人間の負担を一部減らせても初期検索漏れと後段の意味的誤りが全体品質を支配するため、単一の平均正解率ではレビュー工程の信頼性を示せない。
- Limitations: 特定疾患についての既存レビュー1件、商用プラットフォームへの依存、原本の人手判定を参照とした評価である。他の疾患や経済モデル、文献種類への汎化と、検索漏れの改善は追加検証が必要。
