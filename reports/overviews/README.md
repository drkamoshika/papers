## 最新更新 — 2026-W47（11月17〜21日）

11月17〜21日の週次追加38件を既存の7分野へ位置づけ直した。共通して見える変化は、最終的な正解率だけを測る段階から、生成中の忠実性、改善履歴と証拠の保持、推論時の資源管理、外部検証・比較試験・実装準備度を分けて測る段階への移行である。ただし、異なる課題間で同じ改善が再現されたことを意味しない。

- 言語モデル: SynCheck、DeepSeekMath、PagedAttentionにより、生成中の検証、学習、配信資源を同じ処理系の異なる層として整理。
- エージェント: 自己改善の手順だけでなく、改善理由・評価文脈・矛盾する証拠を後続判断へ保持できるかが焦点。
- 評価・安全性: 平均正答率や説明文から、処理中の監視、証拠来歴、介入後の行動変化を分けた評価へ。
- 医療AI: RCT、外部検証の成熟度、介入試験、実装準備度を区別し、研究数と患者利益を同一視しない。
- 表形式・時系列・因果: 部分観測下の状態推定を加え、観測・識別可能性・制御の共同設計を優先。
- 次イベント予測: 直接の新規比較はなく、部分観測と長期整合性という既存課題を維持。
- 神経科学: 回路機構の直接的新証拠はなく、臨床神経AI・EEGでは外部妥当性と実装条件を追加。

## 収録範囲と確認方法

対象は2026-11-16時点の収録スナップショット（基礎774件・新着264件）です。2026-11-18の改稿は、この範囲の技術・比較・事例の詳説です。

全論文を同じ重さで引用する系統的レビューではなく、基盤・転換点・直近の検証を選ぶ横断レビューです。基礎・新着は収録先の区別で、古さは個々の公開日から確認できます。

技術の系譜、論文間の位置づけ、実験から導く解釈と次の課題は編者の整理です。直接の引用関係や商用普及率を確定するものではありません。

初版の22件に加え、改稿では25件の一次資料を確認しました（重複あり）。要旨・本文・検索掲載箇所の範囲を引用文献に記録しています。全件の全文精読や独立再現を意味しません。

数値は論文の報告値です。異なるデータ・分割・指標の比較を統一順位へ変換していません。説明用の計算例は実測値と区別しています。

## 更新方法

毎週、7分野すべてについて「現在地」「理解の変化」「新しい根拠」「まだ言えないこと」「未解決課題」「重要文献」を更新する。大きな進展がない分野も、変更なしと判断した根拠を残す。週ごとの差分は `reports/weekly/`、公開用の同一データは `docs/overview.json` に保存する。詳細は [更新仕様](../../docs/LIVING_REVIEW.md) を参照。
